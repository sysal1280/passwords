# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Passwords**, please report it responsibly.

**Do not open a public GitHub issue.**

Instead, use one of the following private channels:

- GitHub Security Advisories:  
  https://github.com/sysal1280/passwords/security/advisories/new

- Email:  
  sysal@tuta.io

We will review reports as quickly as possible and coordinate a fix and disclosure if needed.

Thank you for helping keep the project secure.
