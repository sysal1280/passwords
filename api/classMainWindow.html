bool MainWindow::killGpgAgent ( )

Attempts to terminate any running GPG agent instance.

This function invokes the gpgconf utility with the –kill gpg-agent command to stop the GPG agent process. It waits for the command to start and finish within reasonable timeouts, and logs diagnostic information using Qt's logging facilities.

The function returns true if the gpgconf process starts successfully, finishes normally, and exits with a zero exit code. If the process fails to start, times out, or exits with an error, the function returns false.

Note
Any output or error text produced by gpgconf is written to the debug log for troubleshooting.
Returns
true if the GPG agent was successfully terminated or was not running; otherwise false.
