 If a security vulnerability is discovered in {\bfseries{Passwords}}, it should be reported responsibly.

{\bfseries{Do not open a public Git\+Hub issue.}}

Instead, use one of the following private channels\+:


\begin{DoxyItemize}
\item Online submission\+: \href{https://github.com/sysal1280/passwords/security}{\texttt{ https\+://github.\+com/sysal1280/passwords/security}}
\item Email reporting\+: \href{mailto:sysal@tuta.io}{\texttt{ sysal@tuta.\+io}}
\end{DoxyItemize}

Reports are prioritised and reviewed as quickly as possible, including coordination of fixes and management of disclosure via Git\+Hub.

\hypertarget{md_SECURITY_autotoc_md9}{}\doxysection{\texorpdfstring{Rewards \& Recognition}{Rewards \& Recognition}}\label{md_SECURITY_autotoc_md9}
The time and effort security researchers invest in helping keep {\bfseries{Passwords}} safe is greatly appreciated. To acknowledge meaningful contributions, the following forms of recognition are offered\+:\hypertarget{md_SECURITY_autotoc_md10}{}\doxysubsubsection{\texorpdfstring{$<$strong$>$\+CVE Credit$<$/strong$>$}{<strong>CVE Credit</strong>}}\label{md_SECURITY_autotoc_md10}
If a report results in a confirmed, fixable security vulnerability, the project will\+:


\begin{DoxyItemize}
\item Request a CVE ID through Git\+Hub’s security advisory process
\item Credit the reporter in the advisory (unless anonymity is preferred)
\end{DoxyItemize}\hypertarget{md_SECURITY_autotoc_md11}{}\doxysubsubsection{\texorpdfstring{$<$strong$>$\+Public Recognition$<$/strong$>$}{<strong>Public Recognition</strong>}}\label{md_SECURITY_autotoc_md11}
With permission, the project will also\+:


\begin{DoxyItemize}
\item Acknowledge the contribution in the commit history
\item Credit the reporter in the release notes associated with the fix
\item Optionally include a link to a website, Git\+Hub profile, or handle
\end{DoxyItemize}

Anonymity is fully respected if preferred.\hypertarget{md_SECURITY_autotoc_md12}{}\doxysubsubsection{\texorpdfstring{$<$strong$>$\+Swag$<$/strong$>$}{<strong>Swag</strong>}}\label{md_SECURITY_autotoc_md12}
As a small token of appreciation, project‑themed swag such as stickers, stationery, or mugs can be provided. If this is of interest, it can be mentioned when submitting a report.
