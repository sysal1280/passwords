\doxysubsection{Detailed Description}
A custom QTree\+Widget that\+: 


\begin{DoxyItemize}
\item paints a watermark when empty
\item supports drag and drop
\item emits a signal when an item is dropped so \doxylink{classMainWindow}{Main\+Window} can handle the logic 
\end{DoxyItemize}
