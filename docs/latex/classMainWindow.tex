{\footnotesize\ttfamily bool Main\+Window\+::kill\+Gpg\+Agent (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Attempts to terminate any running GPG agent instance. 

This function invokes the {\ttfamily gpgconf} utility with the {\ttfamily --kill gpg-\/agent} command to stop the GPG agent process. It waits for the command to start and finish within reasonable timeouts, and logs diagnostic information using Qt\textquotesingle{}s logging facilities.

The function returns {\ttfamily true} if the {\ttfamily gpgconf} process starts successfully, finishes normally, and exits with a zero exit code. If the process fails to start, times out, or exits with an error, the function returns {\ttfamily false}.

\begin{DoxyNote}{Note}
Any output or error text produced by {\ttfamily gpgconf} is written to the debug log for troubleshooting.
\end{DoxyNote}
\begin{DoxyReturn}{Returns}
{\ttfamily true} if the GPG agent was successfully terminated or was not running; otherwise {\ttfamily false}. 
\end{DoxyReturn}
