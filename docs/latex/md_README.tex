 A free, open source, offline password manager powered by GPG.

Managing passwords securely is essential, yet many people still avoid password managers due to cost, cloud‑storage requirements, or distrust of proprietary systems. \doxylink{namespacePasswords}{Passwords} takes a different approach\+: it is a fully offline, cross‑platform, GPG based password manager designed for individuals, professionals, and high‑security environments.

By removing subscriptions, internet dependencies, and closed ecosystems, \doxylink{namespacePasswords}{Passwords} makes strong credential management accessible to everyone. Suitable for everyone from home users to Tier‑0/\+Tier‑1 enterprise environments.\hypertarget{md_README_autotoc_md1}{}\doxysubsubsection{\texorpdfstring{Key Principles}{Key Principles}}\label{md_README_autotoc_md1}

\begin{DoxyItemize}
\item GPG‑based encryption.
\item Your passwords never leave your device. ~\newline

\item No cloud sync, no telemetry, no network access required.
\item Fully auditable and open‑source.
\item Transparency is at the heart of this project.
\item No subscriptions, no vendor lock‑in, no proprietary services.
\item Cross‑platform support for Linux, mac\+OS and Windows.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md2}{}\doxysubsubsection{\texorpdfstring{Features}{Features}}\label{md_README_autotoc_md2}

\begin{DoxyItemize}
\item Uses GPG for strong, proven cryptography to protect private password information.
\item Supports hardware‑backed keys (smartcards, Yubi\+Keys, etc.)
\item Supports multiple GPG keys for detailed segmentation of protected resources.
\item Supports time‑based codes (TOTP).
\item Possessing the database alone is not enough to compromise passwords — decryption requires private key(s), which can be stored on a hardware token.
\item Metadata is encrypted, including entry names and structure, preventing attackers from learning anything useful even if they obtain the database.
\item Cross‑platform desktop application. Supports {\bfseries{Linux}}, {\bfseries{Mac\+OS}} and {\bfseries{Windows}}.
\item No proprietary dependencies. Everything used throughout this project is completely open source.
\item 100\% open‑source, transparent, and auditable.
\item Secure by design.
